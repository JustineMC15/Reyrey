# Room Naming Convention

Use the format:

`A#R#`

- `A#` = Area number
- `R#` = Room number
- `S#` = Shrine number
## Examples

- `A0R1` — Tutorial, Room 1
- `A1R1` — Valecourt Fields, Room 1
